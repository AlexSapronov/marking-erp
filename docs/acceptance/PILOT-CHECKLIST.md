# Условия корпоративного пилота

Обновлено: 27.10.2026. Проектное решение, если явно не указано иное.


- Контракты критических API зафиксированы версиями и тестами; закрыты BLOCKER либо соответствующие функции отключены.
- Чистая PostgreSQL, миграции, seed шести групп, личные учётные записи, HTTPS, backup и пробное восстановление.
- Windows signer на целевом ПК проверяет сертификат и подписывает эталонные bytes; токен работает без постоянных админ-прав.
- MERTECH S55 и S45 Grip: полный КМ, GS/AIM/Enter, две сессии, сон/reconnect, длинный crypto; scanner raw не теряется.
- Принтер58×40: реальное сканирование PDF и физической этикетки, читаемость и требуемое качество печати.
- Владелец отдельно разрешает перечень продуктивных мутаций, GTIN/КМ, лимит стоимости и участников пилота.
- После каждой мутации сохраняются ID, ответ, квитанция и фактическая сверка; unknown останавливает расходующие повторы.
- Проверены per-invoice transfer, смена состава, stop/restore и ноль новой эмиссии при reprint.
- Пользовательские инструкции и build SHA доступны; ответственность за разбор неизвестных результатов назначена.

Этот список не является разрешением выполнить боевые операции. Сейчас ни одна такая операция не выполнялась.

Для каждой проверки заполняется [протокол](PILOT-RECORD.md). Инструкции по ролям —
в OPERATOR-GUIDE.md в корне офлайн-пакета. Не выполненные сценарии отмечаются явно.
