## Результаты

Для каждого выбранного сценария A–T создайте отдельную строку. Значения результата:
«пройден», «не пройден», «не выполнялся». Пропуск не считается успешной проверкой.

| Сценарий | Номер документа / ID операции | Внешний ID и квитанция | Проверенный факт / оборудование | Результат | Обращение и ответственный |
|---|---|---|---|---|---|

## Обязательные остановки

При unknown, расхождении состава/владельца/статуса, неверной подписи или непонятном
исходе печати остановить соответствующий сценарий и зарегистрировать проблему.
Не подтверждать результат вручную ради продолжения презентации. Зафиксировать
исходную операцию, время, квитанцию и план сверки. Разрешение локального обращения
не заменяет подтверждение внешней системы.
