# Очередь внешних операций и подпись

Дата: 25.10.2026. Проектное решение, если явно не указано иное.


Операция хранит точные bytes/hash, org, actor, target_revision, policy_version, contract_version и idempotency key.
Состояния: prepared → awaiting_signature → queued → dispatching → submitted → checking → confirmed.
Ветви: rejected, blocked, unknown, cancelled_before_dispatch. Терминальные значения не путаются с внешними статусами КМ.
Читающие запросы допускают backoff+jitter, лимиты по connection и Retry-After. Изменяющие/расходующие GET классифицируются по семантике.
После timeout/сбоя на dispatching — unknown; никакого автоматического повторного заказа/выделения GTIN/получения расходуемого блока.
Reconcile выполняет только чтение. При недостаточных данных нужен разбор с привязкой внешнего ID и доказательством совпадения состава/организации.
Квитанция и итоговое состояние сохраняются отдельно. Успех отправки не означает успешную бизнес-операцию.

Worker использует DB claim/lease/fencing. Истечение lease после начала HTTP не разрешает другому worker повторить мутацию:
сначала unknown и сверка. Ответ старого fence хранить как evidence, не применять бесконтрольно к новому состоянию.
При снятии permission/остановке документа повторно проверять разрешение до dispatch; старое согласование не даёт бессрочного права отправки.

Подписант: исходящие HTTPS poll с Windows, bearer/mTLS, allowlist типов, org и certificate thumbprint,
base64 exact bytes + SHA256, lease/fence/expiry; один поток токена. Возврат подписи проверяет задачу, hash, сертификат и состояние.
Проверку CMS-криптографии и цепочки доверия реализовать поддерживаемым валидатором; наличие сертификата в CMS не считать доказательством подписи.
Не передавать закрытый ключ/ПИН на VPS, не запускать команды из payload. Reboot/offline сохраняет очередь; heartbeat сообщает недоступность.
Win10 без админ-прав может запускать user agent, но установка CryptoPro/драйвера требует подготовленной ИТ рабочей станции.
Фактическая COM-совместимость 32/64-bit, доступность сертификата и подпись эталонных байтов — обязательный пилот.
