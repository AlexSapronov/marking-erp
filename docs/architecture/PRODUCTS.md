# Единая номенклатура

Дата: 25.10.2026. Проектное решение, если явно не указано иное.


Собственные GTIN и карточки приходят из подтверждённого НК, карточка без GTIN остаётся nk_card.
products — идентичность товара, nk_snapshots — внешнее состояние, document_lines — исторический снимок PN/ТН ВЭД.
Нельзя обновлением карточки переписать уже отправленную накладную или этикетку.
Один PN в накладной соответствует одному GTIN; одинаковый GTIN с разными PN допускается с предупреждением.
Несогласованный ТН ВЭД для GTIN блокирует подготовку связанных АТК до разбора.
Источник PN: подтверждённый model/артикул НК или проверенный источник стороннего КМ с provenance; не генерировать из названия.
Изменения НК не теряют локальный dirty draft; показывать diff и конфликт.
