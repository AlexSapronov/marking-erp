# Разделение КМ

Дата: 25.10.2026. Проектное решение, если явно не указано иное.

Wizard: скан→владелец/статус/характеристика/остаток→количество→подтверждение→заказ→PDF→нанесение→отчёт→итоговая сверка. Отдельно показывать reserved и доступный остаток, текущее внешнее количество с checked_at. Unknown сохраняет резерв и предлагает сверку, не кнопку нового заказа. Повтор PDF всегда использует сохранённую версию. Неколичественная характеристика явно не поддерживается этой формой, даже если внешняя система допускает вес/длину.

Общие состояния, accessibility и темы: DESIGN-SYSTEM.md. Серверные ограничения: ../architecture/PERMISSIONS.md.
