# Накладная БМ

Дата: 25.10.2026. Проектное решение, если явно не указано иное.

Реестр: номер/дата, поставщик, ответственный, этап, КМ/штуки, ошибка. Страница накладной: этапы, строки PN/GTIN/ТН ВЭД/количество/этикетки, вкладки КМ/файлы/отчёты/АТК/история. Импорт показывает объединённые строки и предупреждения до commit. Эмиссия требует summary: сколько новых КМ и для кого. Partial codes показываются как ожидание, PDF недоступен до полноты. Stop запрашивает номер и причину; архив отличается от обычного списка явной меткой.

Общие состояния, accessibility и темы: DESIGN-SYSTEM.md. Серверные ограничения: ../architecture/PERMISSIONS.md.
Это спецификация; рабочих скриншотов ERP пока нет.
