# Перепечать этикетки

Дата: 25.10.2026. Проектное решение, если явно не указано иное.

Поиск через документ/КМ→точная версия→причина→preview58×40→число копий/профиль принтера→PDF/печать→контрольный скан по правилу. Нет полного сохранённого payload — операция заблокирована, не собирать crypto из КИ. Downloads и confirmed_printed различаются. Официальная перемаркировка — отдельный сценарий с API gate, не fallback перепечати. В истории видны пользователь, время, версия и результат контроля; ТСД не имеет раздела.

Общие состояния, accessibility и темы: DESIGN-SYSTEM.md. Серверные ограничения: ../architecture/PERMISSIONS.md.
Это спецификация; рабочих скриншотов ERP пока нет.
