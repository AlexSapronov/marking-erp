# Национальный каталог

Дата: 25.10.2026. Проектное решение, если явно не указано иное.

Реестр: PN, GTIN, бренд, ТН ВЭД, категория, локальный и внешний статус, checked_at, ответственный. Фильтры публикации/черновиков/дублей/dirty. Drawer: атрибуты по схеме, source snapshot, diff, история. Wizard Excel: файл→mapping→предпросмотр ошибок/дублей→подтверждение→построчный результат. Отдельная массовая операция PN+ТН ВЭД+бренд показывает выделенные GTIN и безопасно скачивает XLSX. Синхронизация показывает полноту, окно и последнюю ошибку; published duplicates не исчезают автоматически.

Общие состояния, accessibility и темы: DESIGN-SYSTEM.md. Серверные ограничения: ../architecture/PERMISSIONS.md.
Это спецификация; рабочих скриншотов ERP пока нет.
