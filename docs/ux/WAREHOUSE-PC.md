# Склад на ПК

Дата: 25.10.2026. Проектное решение, если явно не указано иное.

Назначенные приёмки/отгрузки: номер, дата, поставщик, КМ/единицы, исполнитель, статус. Документ: sticky поле скана, счётчик сохранённых сканов, ошибки последнего скана, список событий. Верифицированная табличная часть заполняется только после «Проверить», а не при каждом пике. Чужой GTIN сразу отклоняется локально. Повторный КИ показывает ошибку и отдельное действие удалить при наличии permission. Завершение доступно только по актуальной успешной проверке. Приёмка и отгрузка одинаково сохраняют сканы в PostgreSQL.

Общие состояния, accessibility и темы: DESIGN-SYSTEM.md. Серверные ограничения: ../architecture/PERMISSIONS.md.
Это спецификация; рабочих скриншотов ERP пока нет.
