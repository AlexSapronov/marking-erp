# Приёмка интерфейса

Дата: 25.10.2026. Проектное решение, если явно не указано иное.


Реальные скриншоты новой ERP получают после реализации в браузере, не из статических макетов и не из старых приложений.
Нужны 22 состояния из SPEC §30: шесть главных, НК/карточка, накладная, АТК, передача, приёмка ПК/ТСД,
проверка/отгрузка ТСД, split, reprint, реестр КМ, права, правила, архив, очередь ошибок.
Для каждого сохранять viewport, роль, build SHA, fixture ID и ожидаемые permissions; данные синтетические без настоящих криптохвостов.
Проверять light/dark, пусто/loading/error, forbidden, stale, unknown, reconnect, клавиатуру, 320/360/390px и1366px.
На ТСД нет разделения, перепечати, НК и админки в базовом профиле, в том числе при прямом URL.
Одна и та же роль на ПК и Android сохраняет одинаковые permissions; адаптивность не меняет полномочия.
