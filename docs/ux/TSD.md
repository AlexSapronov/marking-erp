# ТСД 320px и аппаратный сканер

Дата: 25.10.2026. Проектное решение, если явно не указано иное.

Главная: Приёмка / Проверка КМ / Отгрузка. Кнопки не меньше48px, одна колонка, без горизонтальной прокрутки. Документ: номер+поставщик, прогресс, поле скана с удержанием фокуса, последняя ошибка, «Проверить», «Завершить». При открытии модального окна фокус не перехватывается; после закрытия возвращается в сканер. Звук/вибрация при поддержке устройства дополняют текст. Не вызывать API ЧЗ на каждый пик. При обрыве связи показывать «Не сохранено»; не считать скан принятым до серверного ack. Повтор доставки того же request_id безопасен. После сна/перезапуска загружается центральное состояние. Нельзя ограничивать backend по User-Agent. S55 и S45 Grip проверить отдельно, включая GS/AIM/Enter/раскладку.

Общие состояния, accessibility и темы: DESIGN-SYSTEM.md. Серверные ограничения: ../architecture/PERMISSIONS.md.
Это спецификация; рабочих скриншотов ERP пока нет.
