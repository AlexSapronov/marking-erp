# Ролевая навигация

Дата: 25.10.2026. Проектное решение, если явно не указано иное.


| Группа | Стартовый экран | Основная навигация |
|---|---|---|
| БМ | Мои накладные с блокерами | НК, накладные, мои АТК, проверка КМ, связанные операции/архив |
| Логист | Готовые АТК и приёмка | АТК, передача на склад, результаты/расхождения, ФТС, закрытие |
| Склад | Назначенные задания | Приёмка, отгрузка, проверка, разделение, перепечать, проблемы |
| ТСД | Три крупные карточки | Только приёмка, проверка КМ, отгрузка |
| Специалист | Очередь проблем и всех операций | Все операционные модули, архив/restore, без настроек |
| Администратор | Состояние системы | Все модули плюс пользователи, права, правила, организации, интеграции, аудит |

Пункты меню вычисляются из effective permissions. Прямой URL/API проверяет те же ограничения на сервере.
Смена роли/организации не сбрасывает незавершённый ввод молча. Верхняя панель показывает текущую область.
Администрирование скрыто у специалиста и операционных групп; диагностическая карточка проблемы не раскрывает секреты подключений.
