# Редактор групп и прав

Дата: 25.10.2026. Проектное решение, если явно не указано иное.

Выбрать одну из шести групп, искать permission по модулю, выбирать scope и организации, массово разрешить/запретить/только чтение, восстановить seed. Перед сохранением: diff, зависимости, итоговые эффективные права пользователя, предупреждение об отклонении профиля ТСД. Специалисту administrative permissions недоступны принципиально. Проверка «почему отказано» показывает permission/scope без секретов. Права вступают в силу без рестарта и фиксируются в истории.

Общие состояния, accessibility и темы: DESIGN-SYSTEM.md. Серверные ограничения: ../architecture/PERMISSIONS.md.
Это спецификация; рабочих скриншотов ERP пока нет.
