# Логист и передача на склад

Дата: 25.10.2026. Проектное решение, если явно не указано иное.

Таблица: поставщик, накладные, БМ, организация, ТН ВЭД, КМ/штуки, статус АТК, файлы, передача, приёмка, ФТС. Панель передачи показывает отдельные задания по накладным и фактический состав каждого. Повтор открывает созданное задание. После смены версии — жёлтое stale с diff и явным обновлением. Результат склада: ожидалось/сканировано/принято/недостающие/лишние/проблемные. Закрытие показывает все невыполненные условия; ФТС без контракта имеет объяснимый статус «Интеграция не подтверждена».

Общие состояния, accessibility и темы: DESIGN-SYSTEM.md. Серверные ограничения: ../architecture/PERMISSIONS.md.
Это спецификация; рабочих скриншотов ERP пока нет.
