# Общая дизайн-система

Дата: 25.10.2026. Проектное решение, если явно не указано иное.


Единая оболочка: шапка с организацией/ролью, компактная боковая навигация, рабочий контент, drawer и центр операций.
Светлая/тёмная темы с CSS tokens; системный шрифт, базовый размер14px, табличные числа и моноширинный КИ.
Реестры: строка36–40px, sticky header, сохранённые фильтры/ширины/порядок колонок и pagination.
На ПК целевые ширины1366/1440/1920; drawer около480px с возможностью открыть полноценную страницу.
Статусы: нейтральный draft, синий running, зелёный confirmed, жёлтый warning, красный blocked, серый stopped.
Цвет всегда дополняется текстом/иконкой. Не использовать зелёный для submitted или downloaded.
Компоненты: таблица, filter bar, action menu, progress, inline validation, diff, file version list, scan field, error panel.
Loading/empty/error/forbidden/stale/offline обязательны для каждого экрана. Ошибка отвечает «что произошло» и «что сделать».
Кнопка недоступна с объяснением: например «Нет подтверждения отчёта», «Состав изменился», «Нет доступа».
Клавиатура: видимый focus, Tab порядок, Escape закрывает drawer, Enter не запускает эмиссию без подтверждения.
Ни одна визуальная активность не подменяет серверное состояние. Настройки не показывать необъяснённым JSON.
