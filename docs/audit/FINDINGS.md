# Реестр обнаруженных проблем

Дата: 25.10.2026. Проектное решение, если явно не указано иное.

Все дефекты открыты. Исходные проекты не исправлялись; runtime ERP пока отсутствует.
BLOCKER означает запрет соответствующего переноса/запуска до устранения, а не доказанное нарушение закона.
Нарушений законодательства как установленного факта этот отчёт не заявляет.

## W-001

Доказательство: `gis-trueapi/warehouse_routes.py:109–153; main.py:76–93` на SHA из BASELINE.md.

Исправление: Единая аутентификация, permission и organization/assignment scope на каждом API и файле.

Регрессия: Без сессии 401; ТСД чужой организации и чужое задание 403/404 по принятой политике.

## S-001

Доказательство: `km-split/main.py:77–110,130–141,198–252` на SHA из BASELINE.md.

Исправление: Не переносить HTTP-обвязку; единый RBAC, отдельный signer bearer.

Регрессия: Анонимное чтение задания и запись настроек запрещены; сотрудник склада не меняет настройки.

## A-001

Доказательство: `marking-bm и nk-manager/marking-bm/main.py:172–210; nk-manager/main.py:117–140` на SHA из BASELINE.md.

Исправление: Пароль сотрудника; позднее OIDC; привязка ТСД без общего обхода прав.

Регрессия: Знания имени недостаточно; деактивация и смена группы действуют в активной сессии.

## W-002

Доказательство: `gis-trueapi/warehouse_service.py:94–114` на SHA из BASELINE.md.

Исправление: Проверять равенство ожидаемых количеств строкам при создании задания и при завершении сверки.

Регрессия: План10 и полный состав3 → ok=false; ни API complete, ни UI не закрывают документ.

## S-002

Доказательство: `km-split/km_split/clients.py:98–149; km_split/service.py:76–119,122–132` на SHA из BASELINE.md.

Исправление: Получать подтверждённые признаки; отсутствие данных блокирует эмиссию; повторно проверять перед отправкой.

Регрессия: INTRODUCED+запрещённый statusEx, BOX, отсутствующая или неколичественная характеристика → нет заказа.

## S-003

Доказательство: `km-split/km_split/service.py:302–332` на SHA из BASELINE.md.

Исправление: Отдельный reconciliation после квитанции; done только после совпадения ожидаемых фактов.

Регрессия: Receipt SUCCESS при старом остатке оставляет awaiting_external_state; новая эмиссия не вызывается.

## C-001

Доказательство: `все/marking_bm/codes.py; km_split/codes.py; datamatrix.py` на SHA из BASELINE.md.

Исправление: Разделить strict issued-code parser и scanner decoder; общая модель без изменения криптохвоста.

Регрессия: Кавычки/слеши/91/92 внутри serial и crypto сохраняются; неоднозначная коррекция запрещена.

## Q-001

Доказательство: `nk-manager и marking-bm/nk_manager/nk.py:459–503; marking_bm/worker.py:47–78,106–121` на SHA из BASELINE.md.

Исправление: Lease, fencing token и атомарный claim; recovery только истёкшего lease.

Регрессия: Два worker и рестарт одного → один расходующий запрос; ответ старого lease не применяет переход.

## I-001

Доказательство: `интеграции/API-COMPLIANCE.md` на SHA из BASELINE.md.

Исправление: Держать соответствующие отправки выключенными до контрактных доказательств и контролируемого пилота.

Регрессия: Неподтверждённый тип операции возвращает объяснимый блокер, а не успешный результат.

## U-001

Доказательство: `все UI/nk-manager/web; marking-bm/static; gis-trueapi/templates; km-split/static` на SHA из BASELINE.md.

Исправление: Общий UI-shell и компоненты; перенос сценариев, а не четырёх страниц iframe.

Регрессия: Шесть групп, прямые URL и мобильный viewport; UI совпадает с серверными permissions.
