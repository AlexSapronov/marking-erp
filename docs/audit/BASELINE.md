## Метод

Статический просмотр backend, интеграций, схем SQLite, сканеров, генераторов этикеток и интерфейсов;
запуск доступных Python-тестов на изолированных временных данных; локальное воспроизведение W-002.
Статус PASS означает только перечисленное свойство на закреплённом SHA, а не готовность продукта или юридическое заключение.
FAIL означает наблюдаемый дефект либо несоответствие целевому ТЗ; UNVERIFIED — недостаток доказательств.
Оценки безопасности относятся к переносу в ERP; они не означают, что старое приложение обещало такую же модель доверия.

## Ограничения

Боевые credentials не использовались. Продуктивных запросов к НК, СУЗ, True API и подписанту не было.
Новая PostgreSQL, браузер ERP, реальные ТСД, принтер и Windows/CryptoPro здесь не проверялись.
Не все контракты доступны: полный True API превышает лимит чтения, PDF СУЗ отвечает 403.
Контрольная точка не закрыта для массового переноса: см. CHECKPOINT.md.
Перед переносом nk-manager обязательно получить новый main и проверить diff относительно этого SHA.
